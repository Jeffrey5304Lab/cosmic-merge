## （已解決）原始發現：黑洞/恆星內容對絕大多數玩家「看不到」
我跑了平衡模擬（120 局，天真投放策略：置中／隨機／三欄）：
- 分數中位數約 5.5k–7.8k，最高階級只到 **Saturn(8)～Jupiter(9)**，**0/120 局到達太陽(10)**。
- 也就是說：要先做出「兩顆太陽」才會有第一次黑洞——這對隨機玩家幾乎不可能，
  熟練玩家才有機會。剛做的黑洞＋恆星發現是很棒的長線目標，但**多數玩家一輩子看不到**。

**這不是 bug，是設計取捨**，我沒有擅自改難度（那是主觀且風險大的變動）。給你幾個方向早上選：
1. **維持現狀**：當作極限長線目標（很多合成遊戲頂端本就幾乎不可達）。
2. **讓第一次黑洞更好達成**：例如把太陽設為「可合成鏈」的中段而非頂端、或加一個
   「接近太陽時給提示/協助」、或調整上層星球權重讓爬塔更快。
3. **加一個保底展示**：首次做出土星(8)時，用小動畫預告黑洞長怎樣，讓玩家有盼頭。
我傾向 (3)＋輕度 (2)，但等你定調再動難度。

### `773e85c` / `8d8de2d` polish
- 太陽在三角光芒後方加了一層暖色呼吸光暈，跟 8 顆系外恆星視覺一致、更有質感

- 發現橫幅改 RWD（窄手機不再截斷）；EVOLUTION/STARS 分頁加大觸控區。

### `7d48800` 揭示黑洞目標 + 瀕死時錘子提示（留存 / 廣告誘因）
以玩家視角：核心新玩法（兩顆太陽→黑洞→發現新恆星）原本**完全沒被告知**，玩家可能永遠不知道。
- 首次合成出太陽時跳一次性 toast 說明黑洞目標（已發現過恆星就不再提示）。
- 棋盤瀕死（inDanger）時錘子鈕輕輕脈動——在最緊張當口提示「可敲一顆解圍」，
  沒庫存則點擊＝看廣告兌現。這是誠實、對玩家有利的工具提示，也自然提高廣告觀看。

### `4e7ab05` render 煙霧測試
一般測試不會跑 canvas 繪製（無頭無 document），恆星光冕/黑洞的拼字錯誤只有瀏覽器才會炸。
新增假 2D context，把每階星球 + 黑洞各階段都畫一遍，讓 CI 能抓到繪製路徑的執行期錯誤。

### `9a3e656` 每顆恆星獨特外觀 + 黑洞質感升級
- 8 顆系外恆星各有專屬光冕（Proxima 紅矮閃焰、Sirius 相機繞射星芒、Vega 柔和冷暈、
  Arcturus/Betelgeuse 巨星翻騰脈動、Rigel/Deneb 放射長芒、Polaris 北極星大四芒），
  表面加了 limb-darkening + 熱核 + 各自紋理（對流米粒 / 黑子 / 繞射核）。
- 黑洞新增：相對論極噴流、落入餘燼（越近越熾紅）、愛因斯坦環（上下最亮）。
- 新增 `PlanetTier.starStyle` / `corona` 欄位驅動。
